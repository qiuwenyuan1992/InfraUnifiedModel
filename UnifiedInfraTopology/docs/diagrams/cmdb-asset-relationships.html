建模边界

  • 服务器与网络设备统一为 device。
  • 设备保存 all_ips[] 和结构化 device_ip_info[]；带外 IP 可经 MySQL 辅助索引反查设备。
  • GPU 保存由 gpu_uplink.gpu_ip 汇总的 ip_addresses[]；空值不写入。
  • 不建立地址节点、服务器端口节点或网卡端口节点。
  • 普通服务器通过 server_tor_ports 直接上联 ToR 端口；GPU 通过 gpu_uplink 上联。
  • POD 建立统一实体，以 plane 区分管理面、计算面等平面。
  • compute_plane 只用于关系解析，不建立节点。
  • 数据中心是物理查询与同步范围；不建立 POD 到数据中心关系。
  • RPP 和 UPS 的变压器引用只用于校验，不建立直连边。
  • 楼栋、房间、模组和逻辑 IDC 暂保留引用属性。
  • 供电上游止于变压器。

全量同步清理

T = 本轮统一同步时间

  • 所有本轮见到的节点和关系刷新 synced_at=T。
  • 十一类 API、关系解析和图写入全部成功后，才删除 synced_at<T。
  • 任一步失败都不清理。
