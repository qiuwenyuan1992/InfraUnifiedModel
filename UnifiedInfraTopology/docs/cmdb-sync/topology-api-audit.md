# 拓扑API审计与收敛建议

## 范围与结论

初始审计只读核对实现及调用关系；用户确认后已完成第一批行为等价清理，不调整公开API行为、不删除页面功能。清理前拓扑生产代码约2701行，相关测试约2746行；测试及生成的Swagger不应计作业务接口实现。

六个拓扑接口均有Web实际调用，当前不能直接删除：

|接口|实际用途|处理|
|---|---|---|
|node|三维对象完整属性按需查询|保留|
|neighbors|设备和三维视图手动一跳展开|保留|
|roots|数据中心/POD根目录|保留|
|children|数据中心→机柜→设备、POD→成员设备|保留|
|device-context|设备供电/GPU/网络固定路径|保留独立业务职责|
|scene|三维分页层级及网络场景|保留，收敛内部实现|

同步任务管理11条路由属于另一业务模块，本次不混入拓扑收敛。

## 第一批：行为等价的代码收敛

1. `internal/service/topology_browse.go` 的来源ID重复校验复用已有 `inventoryID`，保留稳定ID规范及长度限制。
2. `src/composables/useTopology.ts` 删除仅被测试调用的旧 `locate()` 和相应旧实体类型状态；将请求取消、错误回归迁移到当前 `loadDeviceContext`/手动展开流程。
3. `useSpatialScene.ts` 删除未使用的 `children` 接口要求、`scenePage` 及无调用的分页状态暴露；内部实际分页状态保留。
4. `src/services/topology.ts` 删除无调用的 `identityHelp`。不要移除仍供当前页面使用的名称/类型展示函数。
5. Scene网络读取统一到现有正式批量仓储，去掉逐节点备用路径。将SceneNetwork明确纳入读取仓储接口，迁移测试替身及保留入向/平行边、预算和缺归属负例，不通过删除测试掩盖行为差异。

## 第一批实施结果

- 后端SceneNetwork成为读取仓储的必需能力，删除可选接口和53行逐节点备用遍历；空间归属的有界读取不变。
- 来源ID使用现有inventoryID校验，StableID规范、长度及权限边界保持原样。
- 前端删除旧locate/entityType、identityHelp、无消费者的scenePage状态及未使用children依赖；内部sceneAfter和真实分页逻辑保留。
- 相关生产代码净减少96行；测试迁移保留错误、取消、过期响应、入向/平行边、归属缺失/歧义/截断覆盖，补重复种子只批量读取一次的断言。
- 后端全仓测试、repository/service/router竞态检查、vet与三个入口构建通过；前端109条测试、类型检查及生产构建通过。三维构建块体积警告仍存在，没有隐藏。
- 独立审查未发现中高风险回归；公开路由、请求、响应字段、页面交互和错误优先级未改动，Swagger无需重新生成。
- 本次没有现场请求、写图库、同步、迁移数据库或提交代码。后端运行进程需要重启以加载内部实现变更。

## 第二批：需明确契约的调整

- handler与service重复进行身份/默认值规范化：handler保留HTTP严格参数解析，service统一业务规范化。移除重复业务校验会影响非法参数与无权限并存时400/403优先级，须先确定错误契约。
- 三维响应已经带层级，但前端将其扁平化后又从边重建归属和角色层。后续应确定场景层级由后端作为唯一权威，前端仅布局；不能在这次审计中直接改变归属判断或多父状态。

## 第二批实施边界

本批只收敛场景数据职责：`cabinets.devices`、`unassigned`、`network_levels` 为后端权威。新增 `component_owners` 明确唯一且已核验的端口/GPU父节点；未完整读取、无有效归属或多个父节点不输出确认归属，原始边仍保留。

前端将这些字段规范化为布局输入，不再扫描边重建机柜/组件归属，也不从role字符串重新决定层级。渲染层只按后端数值层级设置高度/颜色。手动一跳新增端点可以显示真实边，但不在前端补确认父节点或角色层。

6个路径保留，现有字段不移除；新增字段要求后端先部署并重启，前端同步升级，不增加旧接口兼容分支。本批不调整handler/service的错误优先级，不重规划同步管理接口。

本批已完成：后端组件归属回归覆盖唯一/缺失/歧义/截断，前端不再从边或role字符串推导；无状态节点显示未核验。前端119条测试/类型构建、后端全仓/race/vet/三个入口build通过，独立审查问题已修复。真实只读POD248场景返回新增字段并保留截断，约311毫秒。没有写图、同步、迁移或提交；Swagger已更新。

## 必须保留

JWT与service权限不是同一检查；目录游标绑定用户/来源/父节点；图读取仍需校验VID、类型、来源、关系矩阵、rank及特殊NULL；实际请求预算和节点缓存各有职责。不能以减少文件为理由删除这些边界。

## 验证门禁

第一批不修改公开路由/请求/响应，不增加兼容分支。每项迁移测试后执行前后端全量测试、竞态、类型检查、构建与diff检查。第二批另行评审，再确定接口重规划；本阶段未运行现场请求或修改数据。
