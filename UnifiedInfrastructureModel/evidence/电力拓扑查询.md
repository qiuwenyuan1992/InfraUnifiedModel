# 电力拓扑查询指南

## 电力拓扑关系结构

### 实体关系图
```
数据中心(DataCenter)
├── 模组(IDCModule)
│   ├── UPS组(UPSGroup)
│   │   ├── UPS设备(UPSDevice)
│   │   └── 列头柜(RemotePowerPanel)
│   └── 楼宇(Building)
│       └── 房间(Room)
│           ├── 列头柜(RemotePowerPanel)
│           └── 机柜(Cabinet) [由列头柜供电]
```

### 关系类型
- `HAS_UPS_GROUP`: 模组 -> UPS组
- `HAS_UPS_DEVICE`: UPS组 -> UPS设备
- `HAS_REMOTE_POWER_PANEL`: UPS组 -> 列头柜
- `CONTAIN`: 房间 -> 列头柜/机柜（空间包含关系）
- `POWER_SUPPLY`: 列头柜 -> 机柜（供电关系）

## 常用查询示例

### 1. 查询数据中心的电力拓扑
```cypher
// 查询数据中心的模组及其UPS组
MATCH (dc:DataCenter {dc_id: 6})-[:HAS_MODULE]->(m:IDCModule)-[:HAS_UPS_GROUP]->(ug:UPSGroup)
RETURN dc.name AS dataCenter, m.idc_module_name AS moduleName, ug.code AS upsGroupCode, ug.ups_group_id_tag AS upsGroupTag

// 查询数据中心的UPS设备（通过模组和UPS组）
MATCH (dc:DataCenter {dc_id: 6})-[:HAS_MODULE]->(m:IDCModule)-[:HAS_UPS_GROUP]->(ug:UPSGroup)-[:HAS_UPS_DEVICE]->(ud:UPSDevice)
RETURN dc.name AS dataCenter, m.idc_module_name AS moduleName, ug.code AS upsGroupCode, ud.code AS upsDeviceCode, ud.ups_brand AS brand, ud.ups_capacity AS capacity

// 查询数据中心的列头柜（通过模组、UPS组和房间）
MATCH (dc:DataCenter {dc_id: 6})-[:HAS_MODULE]->(m:IDCModule)-[:HAS_UPS_GROUP]->(ug:UPSGroup)-[:HAS_REMOTE_POWER_PANEL]->(rpp:RemotePowerPanel),
      (r:Room)-[:CONTAIN]->(rpp)
RETURN dc.name AS dataCenter, m.idc_module_name AS moduleName, ug.code AS upsGroupCode, r.name AS roomName, rpp.code AS rppCode, rpp.row_rated_current AS ratedCurrent
```

### 2. 查询UPS组下的设备
```cypher
// 查询UPS组下的UPS设备
MATCH (ug:UPSGroup {inst_id: 28})-[:HAS_UPS_DEVICE]->(ud:UPSDevice)
RETURN ug.code AS upsGroupCode, ud.code AS upsDeviceCode, ud.ups_capacity AS capacity

// 查询UPS组下的列头柜
MATCH (ug:UPSGroup {inst_id: 28})-[:HAS_REMOTE_POWER_PANEL]->(rpp:RemotePowerPanel)
RETURN ug.code AS upsGroupCode, rpp.code AS rppCode, rpp.row_rated_current AS ratedCurrent
```

### 3. 查询完整的电力拓扑路径
```cypher
// 查询完整的电力路径：数据中心 -> 模组 -> UPS组 -> UPS设备 -> 列头柜 -> 房间
MATCH (dc:DataCenter)-[:HAS_MODULE]->(m:IDCModule)-[:HAS_UPS_GROUP]->(ug:UPSGroup),
      (ug)-[:HAS_UPS_DEVICE]->(ud:UPSDevice),
      (ug)-[:HAS_REMOTE_POWER_PANEL]->(rpp:RemotePowerPanel),
      (r:Room)-[:CONTAIN]->(rpp)
RETURN dc.name AS dataCenter,
       m.idc_module_name AS moduleName,
       ug.code AS upsGroupCode,
       ud.code AS upsDeviceCode,
       rpp.code AS rppCode,
       r.name AS roomName,
       ud.ups_capacity AS capacity,
       rpp.row_rated_current AS ratedCurrent
```

### 4. 查询UPS设备的详细信息
```cypher
// 查询UPS设备及其关联信息
MATCH (dc:DataCenter)-[:HAS_MODULE]->(m:IDCModule)-[:HAS_UPS_GROUP]->(ug:UPSGroup)-[:HAS_UPS_DEVICE]->(ud:UPSDevice)
WHERE ud.inst_id = 2570
RETURN dc.name AS dataCenter,
       m.idc_module_name AS moduleName,
       ug.code AS upsGroupCode,
       ud.code AS upsDeviceCode,
       ud.ups_brand AS brand,
       ud.ups_capacity AS capacity,
       ud.battery_brand AS batteryBrand,
       ud.battery_num AS batteryNum
```

### 5. 查询列头柜的供电路径
```cypher
// 查询列头柜的供电来源
MATCH (rpp:RemotePowerPanel {inst_id: 606})<-[:HAS_REMOTE_POWER_PANEL]-(ug:UPSGroup),
      (ug)<-[:HAS_UPS_GROUP]-(m:IDCModule),
      (m)<-[:HAS_MODULE]-(dc:DataCenter)
RETURN dc.name AS dataCenter,
       m.idc_module_name AS moduleName,
       ug.code AS upsGroupCode,
       rpp.code AS rppCode,
       rpp.row_rated_current AS ratedCurrent,
       rpp.row_rated_voltage AS ratedVoltage
```

### 6. 查询电力统计信息
```cypher
// 查询数据中心的电力统计
MATCH (dc:DataCenter {dc_id: 6})-[:HAS_MODULE]->(m:IDCModule)
OPTIONAL MATCH (m)-[:HAS_UPS_GROUP]->(ug:UPSGroup)
OPTIONAL MATCH (ug)-[:HAS_UPS_DEVICE]->(ud:UPSDevice)
OPTIONAL MATCH (ug)-[:HAS_REMOTE_POWER_PANEL]->(rpp:RemotePowerPanel)
RETURN dc.name AS dataCenterName,
       count(DISTINCT ug) AS upsGroupCount,
       count(DISTINCT ud) AS upsDeviceCount,
       count(DISTINCT rpp) AS rppCount,
       sum(ud.ups_capacity) AS totalUpsCapacity,
       sum(rpp.row_rated_current) AS totalRppCurrent
```

### 7. 查询按楼宇分组的电力信息
```cypher
// 查询各楼宇的电力设备分布（通过房间的列头柜）
MATCH (b:Building)-[:CONTAIN]->(r:Room)-[:CONTAIN]->(rpp:RemotePowerPanel),
      (rpp)<-[:HAS_REMOTE_POWER_PANEL]-(ug:UPSGroup),
      (ug)<-[:HAS_UPS_GROUP]-(m:IDCModule),
      (ug)-[:HAS_UPS_DEVICE]->(ud:UPSDevice)
RETURN b.name AS buildingName,
       count(DISTINCT ug) AS upsGroupCount,
       count(DISTINCT ud) AS upsDeviceCount,
       count(DISTINCT rpp) AS rppCount,
       sum(ud.ups_capacity) AS totalUpsCapacity
ORDER BY buildingName
```

### 8. 查询房间内的列头柜
```cypher
// 查询房间内的列头柜及其供电来源
MATCH (r:Room)-[:CONTAIN]->(rpp:RemotePowerPanel),
      (rpp)<-[:HAS_REMOTE_POWER_PANEL]-(ug:UPSGroup),
      (ug)<-[:HAS_UPS_GROUP]-(m:IDCModule),
      (m)<-[:HAS_MODULE]-(dc:DataCenter)
WHERE r.room_id = 395
RETURN r.name AS roomName,
       rpp.code AS rppCode,
       ug.code AS upsGroupCode,
       m.idc_module_name AS moduleName,
       dc.name AS dataCenterName,
       rpp.row_rated_current AS ratedCurrent
```

### 9. 查询机柜及其供电关系
```cypher
// 查询机柜及其供电列头柜
MATCH (c:Cabinet)-[:POWER_SUPPLY]-(rpp:RemotePowerPanel),
      (rpp)<-[:HAS_REMOTE_POWER_PANEL]-(ug:UPSGroup),
      (ug)<-[:HAS_UPS_GROUP]-(m:IDCModule)
WHERE c.inst_id = 3661
RETURN c.code AS cabinetCode,
       rpp.code AS rppCode,
       ug.code AS upsGroupCode,
       m.idc_module_name AS moduleName

// 查询房间内的所有机柜及其供电信息
MATCH (r:Room)-[:CONTAIN]->(c:Cabinet),
      (c)-[:POWER_SUPPLY]-(rpp:RemotePowerPanel)
WHERE r.room_id = 213
RETURN r.name AS roomName,
       c.code AS cabinetCode,
       c.rack_size AS rackSize,
       c.used_u_num AS usedUNum,
       c.spare_u_num AS spareUNum,
       rpp.code AS rppCode,
       rpp.row_rated_current AS rppCurrent
ORDER BY c.code
```

### 10. 查询完整的电力和空间拓扑
```cypher
// 查询完整的拓扑：数据中心 -> 模组 -> UPS组 -> 列头柜 -> 机柜
MATCH (dc:DataCenter)-[:HAS_MODULE]->(m:IDCModule)-[:HAS_UPS_GROUP]->(ug:UPSGroup),
      (ug)-[:HAS_REMOTE_POWER_PANEL]->(rpp:RemotePowerPanel),
      (rpp)-[:POWER_SUPPLY]->(c:Cabinet),
      (r:Room)-[:CONTAIN]->(c)
RETURN dc.name AS dataCenter,
       m.idc_module_name AS moduleName,
       ug.code AS upsGroupCode,
       rpp.code AS rppCode,
       r.name AS roomName,
       c.code AS cabinetCode,
       c.rated_current AS ratedCurrent
ORDER BY dc.name, m.idc_module_name, ug.code, rpp.code, c.code
```

## 注意事项

1. 所有实体都通过`inst_id`字段进行关联
2. UPS组只与模组关联，不直接与数据中心或楼宇关联
3. UPS设备只与UPS组关联，通过UPS组和模组与数据中心间接关联
4. 列头柜与UPS组和房间关联，通过`idc_room`字段关联到房间的`room_id`
5. 房间与列头柜/机柜使用`CONTAIN`空间包含关系
6. 机柜与列头柜通过`row_switch_id_A`和`row_switch_id_B`建立供电关系
7. 机柜与房间通过`phy_room_id`建立空间包含关系
8. 查询时需要通过模组->UPS组->设备/列头柜->机柜的路径进行
