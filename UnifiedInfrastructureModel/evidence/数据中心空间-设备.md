# 数据中心空间-设备查询API

## 作用
查询数据中心中的设备信息，包括设备所在的数据中心、模组、楼宇、房间等空间信息，以及设备SN、IP等关键信息。

## 请求地址
```
http://cmdb.jd.com/pub/api/v3/find/instance/object/device_view?user=cmdb_all&timestamp=1&auth=1
```

## 请求方式
POST

### server_tor_ports 字段说明
当设备类型为服务器或网络设备时，可能会包含此字段，表示设备与上联交换机之间的连接信息。

**字段结构：**
- `ip`: 上联交换机IP地址
- `ip_type`: IP类型
- `ports`: 连接端口列表
- `sn`: 上联交换机设备SN（用于标识设备）

**用途：**
此字段描述了设备（服务器或网络设备）与上联交换机之间的物理连接关系，可用于构建网络拓扑结构。每个数组元素表示一个上联交换机的连接信息。

**示例：**
```json
"server_tor_ports": [
    {
        "ip": "11.97.5.174",
        "ip_type": 1,
        "ports": ["25GE1/0/4"],
        "sn": "21980114493GN2000700"
    },
    {
        "ip": "11.97.5.175",
        "ip_type": 1,
        "ports": ["25GE1/0/4"],
        "sn": "21980114493GN1002671"
    }
]
```

## 设备统一建模说明

服务器和网络设备都是机柜内的终端设备，可以采用统一建模方式。通过对比两个示例文件，我们可以清晰地看到它们的异同点。

### 1. 设备类型对比

**服务器 (device_type_id = 57):**
- `device_type`: "通用服务器"
- `parent_type`: "服务器"
- `parent_type_id`: 52

**网络设备 (device_type_id = 190):**
- `device_type`: "盒式交换机"
- `parent_type`: "网络设备"
- `parent_type_id`: 54

### 2. 统一节点类型
- **节点标签**: `Device` 或 `Equipment`
- **区分属性**: 使用 `device_type`、`parent_type` 和 `device_type_id` 属性区分设备类型

### 3. 共同字段（统一建模基础）
以下字段在服务器和网络设备中都存在，可作为统一建模的基础：

**服务器特有字段:**
- `server_tor_ports`: 上联交换机连接信息（包含IP、端口、SN）
- `server_tor_sn`: 上联交换机SN列表
- `parts_*`: 硬件组件信息（CPU、内存、磁盘等）
- `os_*`: 操作系统信息
- `configure`: 配置信息

**网络设备特有字段:**
- `soft_version`: 软件版本
- `related_racks`: 相关机架信息

### 4. 连接关系建模

**服务器连接关系:**
- 通过`server_tor_ports`字段建立与上联交换机的连接
- 关系类型: `(Server)-[:CONNECTED_TO {port, ip}]->(Switch)`
- 示例: 服务器219428851038连接到交换机21980114493GN2000700

**网络设备连接关系:**
- 作为网络基础设施，通常是被连接的目标
- 关系类型: `(Device)-[:CONNECTED_TO]->(NetworkDevice)`
- 网络设备之间也可能有互联关系
- 网络设备也有IP地址（eth_ip, ilo_ip），可用于管理和监控
- 网络设备通过`role`字段标识设备在网络中的角色（如T0交换机）

### 5. 统一建模建议

```cypher
// 创建统一设备节点
MERGE (device:Device {
    device_sn: "219428851038",
    device_type: "server",
    parent_type: "服务器",
    device_type_id: 57,
    model: "R5300 G4X",
    manufacturer: "ZTE"
})

// 创建网络设备节点
MERGE (switch:Device {
    device_sn: "210235A2BBH19C000214",
    device_type: "network_device",
    parent_type: "网络设备",
    device_type_id: 190,
    model: "S6800-54QF-H3",
    manufacturer: "H3C",
    role: "T0"
})

// 空间关系
MERGE (cabinet:Cabinet {code: "DC5-M2-341-I10"})
MERGE (cabinet)-[:CONTAIN]->(device)
MERGE (cabinet)-[:CONTAIN]->(switch)

// 网络连接关系（服务器到交换机）
MERGE (device)-[:CONNECTED_TO {
    port: "25GE1/0/4",
    ip: "11.97.5.174",
    connection_type: "server_tor"
}]->(switch)
```
