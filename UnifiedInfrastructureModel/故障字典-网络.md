# 故障字典 · 网络领域（v0.1 初稿）

> 权威源：本文件（Git PR 治理）。数据底稿：raw/network/netops_strategies.json（312 条，netops.jd.local 独立实例）。
> 编码规则：`net.对象.现象`（与服务器域同构：域跟部件本体+处置责任走）。
> **范围拍板（2026-11-19）**：故障+性能双轨——流量超限/陡降/掉零/微突发/丢包在网络域即故障；业务定制（专线/机房/业务线）不进编码，归实例属性。
> 严重度：线上刻度为 **A1/A3/A5/A7/A9**（奇数五档，A1 最高档待验证）；字典自有刻度 P1-P3。**A→P 换算未定**（需告警样本验证，勿沿用 S→P 规律）。
> 状态标记：[✓] 已确认 [~] 待评审 [?] 待定。

## 零、与服务器域的跨域对齐（编码前先读）

| 网络域 | 服务器域 | 关系 |
|---|---|---|
| `net.port.down` | `server.nic.link_down` | **同一物理事件两面**（光纤断：交换机侧 Port Down + 服务器侧 Link Down），建关联边不合并 |
| `net.optical.perf.degrade` | `server.optical.*` | 跨域同族（交换机光模块 vs 网卡口光模块），机理同构、编码各建 |
| `net.port.crc_error` | `server.nic.crc_error` | 同族——两侧 CRC 都升 ⇒ 链路本体坏；单侧升 ⇒ 该侧端口/模块问题（诊断分流点） |
| `net.ping.*` | `server.sys.*`（探活预留位） | 网络域探活**已建设**（带内/带外两级），语义可对齐：设备失联 vs 服务器失联 |

## 挖掘判定记录

- **不进编码**：业务定制（专线接入区/托管区/商城/零售/金融/CDN/商业化/HST/海口人行）、设备层级（T0/T1/T2）、采样粒度（10s/1分钟后缀）、推送通道变体（DE/订阅）、测试与自监控策略（【测试】【自监控勿删】）、厂商变体（包守恒 PR/LE/CISCO）
- **A 刻度→字典 P 换算未定**：A1-A9 五档语义从策略名只能初判（A7=硬件类、A1=专线接入区探活+掉零），**必须告警样本定论**——教训：服务器域 S→P 首推就错过一次
- **探活对照**：网络域带内/带外两级探活已建设——服务器域 `server.sys.*` 四预留位可参考此分法（带内/带外组合分辨设备挂 vs 通道断）
