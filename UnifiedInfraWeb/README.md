# UnifiedInfraWeb · 统一基础设施管理台

Vue 3 + TypeScript + Vite + Element Plus 独立管理前端，读取真实 `UnifiedInfraTopology` 同步管理 API。界面为中文，第一期不包含登录、用户、权限管理、JWT、浏览器存储或模拟业务数据。

## 后端服务

后端位于平级 `UnifiedInfraTopology/`；本地开发配置已关闭管理API鉴权并配置私密游标签名密钥，修改开关后要重启HTTP服务。分别运行：

```bash
# 在 UnifiedInfraTopology 目录
go run ./cmd/server -conf config/local.yml
go run ./cmd/worker -conf config/local.yml -process-rounds
```

仅浏览已有任务不需要启动worker；创建后要执行同步才需要worker。任务取消不回滚已写图库，默认没有旧数据清理。不要将免鉴权服务暴露到公共网络。

## 本地启动

推荐 Node.js 22.12+（22 LTS）或 24 LTS，npm 10+。

```bash
npm ci
cp .env.example .env.local
npm run dev
```

开发服务仅监听 `127.0.0.1`。Vite 将 `/v1` 原路径代理至 `VITE_API_PROXY_TARGET`，默认 `http://127.0.0.1:8000`，已核对后端 `config/local.example.yml` 的 `http.host` / `http.port`。无需修改前端 API 路径。`.env.local` 不提交；`VITE_` 变量可能进入浏览器构建，禁止配置任何真实秘密。

后端应已完成控制库迁移并启动 HTTP 服务。开发时在独立本地配置设置：

```yaml
inventory:
  auth:
    enabled: false
```

此配置依赖后端提供相应的本地鉴权开关；本项目不修改后端配置。不要在非本地部署中关闭鉴权或公开绑定。签名分页仍需配置后端私密 `inventory.cursor_key`，不要将其写入前端。401/403 提示后端本地鉴权配置问题，不提供令牌兜底。

HTTP 创建请求仅持久化入队，实际执行需要已获授权的独立 `-process-rounds` Worker。本项目安装、测试、构建均不会创建真实任务、启动 Worker、调用 CMDB 或清理图数据。

## 已实现

- `GET /v1/inventory/sources`：读取全部游标页，选择真实已启用来源；只读来源清单。
- 整轮任务列表：来源 / 状态筛选、20–200 条页大小、签名游标上一页 / 下一页；刷新保留当前游标及筛选，筛选变更回到第一页。
- 仅用户确认创建才 `POST /sync-rounds`，请求体固定 `{source_id, mode:"full"}`；每次新提交用 `crypto.randomUUID()` 生成幂等键，失败重试保留同一键，不自动重试写请求。
- 详情展示后端 15 阶段、成功阶段比例、时间、错误码、阶段计数与整轮/子任务诊断入口。活动阶段计数标为 `—`，不把未完成零值解释为来源为空。
- 取消必须二次确认；运行中的取消等待 Worker 响应，不承诺回滚已写入图数据。
- 诊断抽屉独立保留游标与来源筛选，不发送状态筛选；只展示 API 已脱敏字段。
- 列表每 10 秒刷新当前页；仅选中的活动任务详情每 10 秒刷新，终态/关闭抽屉后停止；页面不可见时跳过轮询。定时器清理、请求互斥、旧响应隔离与 AbortController 取消防止重复请求和串页。
- loading / 空态 / 网络或后端错误均有明确提示。本页统计来自当前后端结果，不显示伪造的全量总数；后端未提供总数，不使用数字页码猜测总页数。

## 拓扑浏览 · 数据中心/POD下钻

当前默认不再选择来源或输入UUID：自动使用唯一启用的CMDB来源（零个/多个明确提示，不任意选择）。进入“拓扑浏览”后选择数据中心→机柜→设备，或POD→直接成员设备；目录每页50项，支持上下页和面包屑返回。POD成员按VID去重，不由机柜标签推导。

选择设备后自动调用 `/device-context` 展示设备→机柜→A/B列头柜→UPS组→变压器、UPS成员旁支，以及GPU和已同步网络上联。没有服务器直连电力的伪造边；备用配置不自动加入主供电链。设备SN快捷查询保留，其他节点可继续手动展开一跳。

目录使用 `/roots`、`/children` 及签名 `next_after` 分页；设备上下文有200节点/400边/40次实际查询预算（每步50边），超限及缺关系明确提示。手动方向/领域筛选不会取消加载中的自动设备视图，切目录、切来源和离开页面会取消旧请求。

43条前端测试及构建通过；真实浏览器已验证IDC机柜分页/设备路径、POD成员目录。服务器 `A514359X5413481` 的只读API显示21节点/20关系，包括8GPU、A/B两列头柜、两个UPS组、4个UPS及两台变压器。此前版本的一跳验收记录如下。

### 保留的一跳接口与历史验收

- 从“拓扑浏览”导航进入；复用真实已启用来源清单及现有 API envelope 的 `data`，不新增登录、JWT 或运行时模拟数据。
- `GET /v1/inventory/topology/node?source_id=...&entity_type=...&stable_id=...` 精确定位；不存在显示 404，不生成占位节点或吞掉 `BAD_TYPE`。
- `GET /v1/inventory/topology/neighbors?source_id=...&entity_type=...&stable_id=...&limit=100&direction=both&edge_type=...` 读取一跳。方向可为 `in/out/both`；可选领域为 `spatial_relation/composition_relation/network_relation/power_relation`。
- 稳定 ID：设备 `device_sn`、GPU `parts_sn`、端口 `port_uuid`、机柜/数据中心/POD `uuid`；变压器/UPS 组/UPS/列头柜使用正整数 `inst_id`（不超过有符号 64 位范围）。按原值精确定位，不支持名称搜索或全图加载。
- 仅用户点击定位自动读取根节点一跳；点击节点后手动展开，关系领域和方向只作用于下一次读取。不轮询、不创建同步任务、不发送拓扑 POST，也无故障模拟。
- Cytoscape 画布支持缩放、适应、拖拽与增量节点定位；现有节点位置不重排。关系按实际 ID 去重，保留平行边、原方向、A/B 路 `power_path`、plane 与字符串 rank；物理互联箭头仅表示存储方向。
- 每次最多 100 条关系，截断明确提醒；画布上限 500 节点 / 1000 关系，超限完整拒绝本次合并并保留已有图。切换来源、类型、稳定 ID 清空旧图，AbortController 与代次校验防止旧响应串图；离开页面销毁画布及观察器。
- 节点/关系属性与来源、创建/同步时间来自 API；时间字段允许 null。图可能含旧节点或旧边，读取不是原子全局快照，不保证旧边收敛。空邻居不代表整个来源为空。
- 后端鉴权启用时 401/403 提示当前控制台无登录，应检查本地 `inventory.auth.enabled` 及读取权限；不要公开免鉴权服务。503 表示图库或服务未就绪，不触发任何写请求。

本次前端共31个单元测试通过，包含精确查询/GET/取消信号、接口错误、平行边去重、500/1000预算边界、过期请求隔离、停用来源校验，以及headless Cytoscape位置保留和销毁。浏览器发现定位输入框缺注册，已补启动级RED→GREEN回归；设备/GPU画布标签显示类型与SN，避免同型号卡无法区分。TypeScript检查、生产构建通过，运行时依赖审计0漏洞，拓扑模块按需加载。

真实浏览器使用独立临时端口只读验收通过：设备 `A514359X5413481` 显示10节点/9关系（8张GPU卡及机柜）；GPU `1750125024470` 显示4节点/3关系（含两个上联），手动展开聚合口后显示12节点/11关系及所属ToR。没有创建任务或修改图库，没有生成仓库开发报告。

临时验收服务已关闭，用户原8000服务未停止。**后端新增路由必须重启 `go run ./cmd/server -conf config/local.yml` 后生效**；前端Vite热更新后刷新，进入“拓扑浏览”，选择数据中心/POD下钻，或用设备SN快捷查看关联。不存在的资产提示404；只读图库连接故障提示503，不应阻止其他管理API启动。

## 验证与构建

```bash
npm test
npm run build
npm audit
npm run preview
```

`build` 先执行 `vue-tsc --noEmit`，再生成 `dist/`。Vitest 仅替换测试中的 HTTP 传输响应验证 API 契约，不存在运行时 mock 后端。锁文件固定依赖；`.npmrc` 使用 `legacy-peer-deps` 避免本地 npm 10 在升级 Vitest 可选 peer 图时的 `edgesOut` 异常。

`preview` 仅用于预览构建产物，不提供开发 API 代理。部署时应由同源反向代理将 `/v1` 转发至后端；本期无生产鉴权方案，不能直接公开部署本地免鉴权控制台。
