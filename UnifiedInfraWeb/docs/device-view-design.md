# 设备视图试用版

用户已确认：参考 gpu_topology 的视觉组织方式，先做一个版本查看效果；不复制未授权源码或硬编码硬件关系。

## 方案

新增确定性SVG设备图，保留现有Cytoscape关系图切换。相比直接修改力导向图，SVG更适合服务器容器与GPU卡片；相比复制D3示例，它不增加依赖且沿用真实节点和关系模型。

当前调整采用横向排布：IDC仅以顶部文字展示，不画容器框；机柜包含设备，设备包含GPU或接口，UPS组包含成员UPS，同级设备、GPU、端口、UPS成员及各机柜横向排列。空间located_in和组成边不重复绘制连线，折叠关系列表仍保留每条原ID并可查看详情；网络及A/B供电依赖保持连线。POD仅作为成员/标签，不推导数据中心层级。

只有唯一且有效的归属才进入容器；多归属或循环不任意择一，保留独立节点及关系提示。不补造未采集的其他机柜设备、Spine/Core或硬件。其他真实节点列为关联背景，不伪造CPU、NVSwitch、NVLink、带宽或直接服务器供电边。

全部可视节点和边保留原ID、方向、属性，点击复用详情面板；选中对象高亮邻接路径。支持缩放、拖拽、适应画布及领域显示开关；隐藏领域不得改变原始图。多个上联按relation_id绘制偏移曲线；服务器容器是视觉分组，不增加图节点。

## 约束

只消费现有device-context及已展开图，不增加后端请求或写入。没有GPU或网络关系时明确展示缺少数据，不生成示意硬件。布局应覆盖不同GPU数量及共享供电节点，文本安全渲染，预算沿用现有上下文。
